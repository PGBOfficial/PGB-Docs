## Network

- Network: Persian Gulf Blockchain Public Testnet
- Token: PGC
- Token Decimals: 18
- SS58 Prefix: 42
- Consensus: BABE + GRANDPA
- Target Block Time: ~3 seconds

## Validator Policy

Detailed validator requirements, staking and bonding parameters, reward mechanisms, operational requirements, and slashing conditions will be maintained separately in the official PGB Validator Policy documentation.

Public Testnet parameters are experimental and may be adjusted based on network performance, security requirements, test results, and validator feedback.

Mainnet validator requirements and economic parameters will be published separately before the PGB Mainnet launch.

## Important

Validators are responsible for:

- Maintaining a secure and stable validator server.
- Protecting validator and session keys.
- Maintaining reliable network connectivity and validator uptime.
- Keeping the PGB node software up to date.
- Following PGB network and validator policies.
- Monitoring validator operation and responding to critical network updates.

Validator operators should never expose private keys, seed phrases, or other sensitive credentials.
