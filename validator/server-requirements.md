# Server Requirements

The following specifications are recommended for running a validator node on the PGB Public Testnet.

## Recommended Hardware

- CPU: 4 vCPU
- RAM: 8 GB
- Storage: 100 GB SSD/NVMe
- Network: Stable internet connection
- Operating System: Ubuntu 24.04 LTS (64-bit)
- Public IPv4 address
- Server uptime: 24/7

## Network Requirements

PGB is currently in the Public Testnet stage and network traffic is expected to be relatively low during the initial phase.

A stable VPS or dedicated server connection is sufficient for initial validator operation.

Bandwidth and storage requirements may increase as network activity, transaction volume, and blockchain data grow.

## Server Access

Validator operators must have:

- Root or sudo access
- SSH access to the server
- Ability to configure firewall and network ports
- Ability to install and update system packages

## Important

The validator server should be dedicated to validator operation whenever possible.

Validator keys and server credentials must be kept secure and must never be shared publicly.

Hardware, storage, and bandwidth recommendations may be updated during the Public Testnet based on actual network usage and performance data.
